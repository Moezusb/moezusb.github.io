# moezusb.github.io

Personal site of Mohamed Bah: operations, product, and applied AI.

**Live:** [moezusb.github.io](https://moezusb.github.io)

One self-contained `index.html`. No build step, no framework, no tracking. Type is Archivo (variable width, via Google Fonts). The palette is faded grey with forest green for production work and orange for live status.

To change content, edit `index.html` and push to `main`; GitHub Pages redeploys in about a minute.
